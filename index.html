I'm a software developer who started on the front end and enjoys the point where design and code meet: a layout that holds up on a small phone, a button that feels right, a page that loads before you notice it.

When I meet a problem I break it into small parts, build the simplest version that works, then refine it. I use Git on every project, read the documentation before reaching for a library, and pay attention to spacing, contrast and keyboard access.

I want to build useful digital products: sites and tools that solve a real problem for real people, not ones that only look good in a screenshot.
